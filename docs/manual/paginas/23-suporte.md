# Solicitar alteração no sistema

Como pedir correções, mudanças ou funcionalidades novas para a Ávila Ops.

**Índice**

1. Como enviar
2. O que informar
3. Contato

## Como enviar

1.  Descreva o pedido pelo WhatsApp da Ávila Ops ou pelo modelo de solicitação na pasta do projeto no Google Drive.
2.  Para pedidos maiores, preencha o "Modelo de solicitação de alteração ou complemento".

## O que informar

| Campo | Exemplo |
| --- | --- |
| Tipo | Correção, alteração ou funcionalidade nova. |
| Tela | Pedidos, Comissões, Parâmetros... |
| Como está hoje | O que acontece agora, com o passo a passo se for erro. |
| Como deve ficar | O resultado esperado por quem usa. |
| Regra de negócio | Cálculo, limite ou aprovação envolvida. |
| Exemplo real | Um pedido ou valor concreto. |

> **Observação**
>
> Os campos de regra de negócio e exemplo real são os que mais evitam retrabalho.
