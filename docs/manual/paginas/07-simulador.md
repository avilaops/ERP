## Quando usar

Use o simulador para responder rápido a perguntas como "quanto posso dar de desconto nessa leg press para o Maranhão?" sem abrir um pedido.

## Como simular

1.  Acesse o menu **Simulador**.
2.  Escolha o equipamento, o estado de entrega e o desconto.
3.  O simulador mostra o preço final e, para a diretoria, a mesma conta do quadro Só o diretor vê, incluindo a entrada mínima.
